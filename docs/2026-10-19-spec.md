# 英文教練系統 規格書（定案版）

> 日期：2026-10-19　使用者：榮軒（物理治療師，母語繁中，英文初階）
> 一句話：一間只有一個學生的英文補習班。櫃台在手機網頁，成績單放自己的 Supabase，老師（Claude）每次開口前都先翻學習檔案。

## 1. 目標與衡量
- 每天 60–90 分鐘，用「能完成哪些任務」衡量，不考試。
- 起點：**生活英文**（打招呼、數字時間、吃飯、問路交通、購物住宿、日常聊天）→ 進階聊天（時事、興趣、工作簡介）→ 診所工作（身體部位、問診、疼痛評估、運動處方、衛教）。
- 每週日自動重測字彙量，畫趨勢線。

## 3. 教學規則（寫死在後台函式的系統提示，Claude 不得改成一般教學）
1. **先評估**：第一次使用做字彙 20 題（5 級 × 4 字）+ 短文理解 + 情境寫作，估字彙量與 CEFR。
2. **可理解輸入 95%**：A1–A2 句子 ≤ 8 字、只用常用 1000 字 + 當週主題必要字；連續 2 題理解錯 → 自動降難度（level_adjust −1）。
3. **FSI 句型快答（核心，依榮軒 2026-10-19 提供的 FSI 影片）**：重點是「答快，不是答對」。老師給基礎句 → 連續丟提示詞（Japan → She → not…），**3 秒內**開口（可調 2–5 秒），超時提醒「加快」；每個句型代換 **20 次**（可調 10/15/20）再轉換 10 次，接著少量應答／擴展。答錯只閃正確句就往下，不中斷節奏；錯句進句子卡。麥克風自動開、相似度 ≥ 0.8 算對（容忍辨識誤差）。每日統計快答率與平均反應秒數。
4. **間隔重複**：單字卡 + 句子卡兩種，只收練習中遇到或答錯的；SM-2 簡化版排程；新字每日上限 12。
5. **衝刺**：3 週衝刺 + 1 週緩衝，系統自動排，追蹤每日完成率。
6. **用英文做事**：每天一個產出任務，Claude 只修正不代寫。
7. 說明用中文、練習用英文；B1 後逐步英文為主。糾錯要具體（哪個詞、為什麼、該怎麼說）。

## 4. 階段與週主題
| 階段 | 週 | 主題 | 核心句型 |
|---|---|---|---|
| 1 生活 | 1 | 打招呼與自我介紹 | I am / I'm from / Are you…? |
| | 2 | 數字、時間、價錢 | What time / How much / How many |
| | 3 | 吃飯點餐 | I'd like / Can I have / Do you have |
| | 4 | 緩衝（只複習） | |
| | 5 | 問路與交通 | Where is / How do I get to / turn left |
| | 6 | 購物與住宿 | Can I…? / too expensive / I want |
| | 7 | 日常聊天 | I like / I usually / And you? |
| | 8 | 緩衝 | |
| 2 進階聊天 | 9–11 | 時事（簡化短新聞）、興趣嗜好、工作簡介 | I think / I agree / because |
| | 12 | 緩衝 | |
| 3 診所 | 13+ | 身體部位→問診→疼痛評估→姿勢動作→運動處方→衛教 | Where does it hurt / Can you… |
- 解鎖門檻：階段 2 需估計字彙 ≥ 800；階段 3 需 ≥ 1200 且階段 2 任務測驗過。門檻可在設定頁調。

## 5. 頁面（MVP）
1. **登入**：Email + 密碼（Supabase Auth）。
2. **程度評估**：第一次必做。四步：字彙 20 題 → 短文理解 → 情境寫作 → 結果（字彙量 / CEFR / 起點）。每週日自動彈出重測字彙。
3. **今日課程**：四段，各自打勾、可中斷續做。
   - 複習：到期卡片問答，答錯當天重排。
   - 輸入：當週主題短對話 + 中文字彙提示 + 3 題理解題；連錯 2 題降難度。
   - 快答：2–3 個句型 ×（代換 20 + 轉換 10）+ 應答／擴展 4–6 題，3 秒倒數條，自動麥克風，統計快答率。
   - 朗讀：老師準備 6–8 句短文，不翻譯不查字典直接大聲讀，語音辨識估算讀對比例，最後整段再讀一次。
   - 輸出：情境回應或自由日記二選一，打字或語音；回饋三項：聽得懂嗎 / 哪裡錯 / 更自然說法。
   - 結束頁：今日新卡、新字、明天主題、本週任務達成度。
4. **卡庫**：翻閱、搜尋、手動加卡、匯出 CSV。
5. **進度**：字彙量趨勢、每日完成率、本週達成度、錯最多的 5 個句型。
6. **場景/設定**：階段與週主題清單、貼入自訂內容（個資守門員：身分證/生日/電話用規則擋，人名請 Claude 判斷）、模型切換、每日新字上限、朗讀速度。

## 6. 聽與說
- 朗讀：瀏覽器 `speechSynthesis`（en-US），每句有播放鍵，可調速度。
- 語音輸入：`webkitSpeechRecognition` / `SpeechRecognition`，辨識文字再送 Claude。iPhone Safari 支援但準度較弱，聲音由 Apple 伺服器辨識（瀏覽器行為）。不支援時退回打字。

## 7. 資料表（Supabase，全部開 RLS，只有本人可讀寫）
- `profile`：等級、估計字彙量、CEFR、目前階段/週/天、衝刺開始日、每日新字上限、模型、常錯句型摘要。
- `assessments`：每次評估（類型、分數、估計字彙、CEFR、原始作答）。
- `lessons`：每日課程（日期、主題、五段狀態 JSON 含快答紀錄與統計、生成內容 JSON、完成時間）。
- `cards`：卡片（類型 word/sentence、英文、中文、情境、來源、SM-2 欄位：interval、ease、due_at、reps、lapses）。
- `reviews`：每次複習結果（卡片、對/錯、日期）。
- `errors`：答錯紀錄（句型標籤、原句、正確句、日期）→ 統計前 5。
- `curriculum`：階段/週/主題/核心句型（預建，可改）。
- `api_log`：每次呼叫 Claude 的 token 用量（看花費）。
- 預留：`conversations`（第二階段自由對話）、`custom_scenes`（自訂場景）。

## 8. 後台函式 `coach`（Supabase Edge Function）
- 需登入（驗 JWT），只接受本人 user_id。
- 動作（action）：`assess_vocab_list`、`assess_grade`、`lesson_input`、`lesson_drill`、`lesson_output_feedback`、`review_grade`、`pii_check`、`custom_scene_build`。
- 每次請求：伺服器端讀 `profile` 組成「學習狀態」塞進系統提示（規則區固定、狀態區在後），回傳 JSON（用 `output_config.format` 結構化輸出）。
- 系統提示規則區加 `cache_control`，省費用。
- 記 `api_log`。

## 9. 驗收
- 完成評估後顯示字彙量與起始等級。
- 隔天開啟，四段跑完，答錯句子出現在卡庫並排入複習。
- 連續 7 天後進度頁有完整數據。
- 貼入含姓名/身分證的內容被擋下。
